# Journey
What was built, in what order, and why that order. This section is for the
reader who wants to know whether the sequence was intentional. A grower can
skip it and lose nothing.
- `01-arc.md` — the shape of the build in one page: money first, then read-only
  books, then a phone that can see without writing, then density, hygiene,
  and the rooms a business needs.
- `02-timeline.md` — the calendar, cluster by cluster, with the commits that
  closed each one. Git is the ground truth; this page interprets it.
- `03-field-instrument.md` — how a phone was allowed near the farm record
  without ever becoming a second writer.
- `04-still-open.md` — what is not finished, named rather than hidden.
## How to read the dates
The repository history runs from 2026-08-10 to 2026-09-02: 229 commits in
24 days. Built by a solo operator alongside running the farm, in sustained
daily sessions. That is the only line here about intensity; the log does
the rest.
## What the order proves
1. **Why money before a pretty rack screen.** The record had to be able
   to say "owed", "unpriced", and "short" honestly before any surface was
   worth polishing.
2. **What the phone may do.** See the PC's snapshot with its age; capture
   proposals; nothing else.
3. **Integrity-first with residuals, not a finished product.** The open
   items are listed, with what would close them.
