# Doctrine
These laws are the product. Features are downstream. If a change fights a
law, the law wins and the change does not ship. That is how Groundtruth
stays an engine instead of another speaker upgrade.
Each page is short: the law in one sentence, why a grower should care, what
it forbids, what it still allows, and how you can tell it is being kept.

## For builders
The laws travel; the chrome does not. Language, currency, date formats,
paper sizes, and crop defaults are expected extension points for forks in
any country. A fork that keeps the laws is still Groundtruth in spirit. A
fork that drops one — soft money, a phone that writes the farm, a mandatory
cloud — should use its own name. No sermon; just a different product.
A pull request is judged by one question first: **does this make money or
truth softer?** If yes, it is closed. The repository `CONTRIBUTING.md` and
`decisions/README.md` say which paths need operator sign-off before code.
## Where the laws come from
They were written before the code, as signed decisions, and the code was
made to match the signed text. The record of those decisions is kept in
`../_raw/`. The pages here restate them for a public reader; they do not
outrank them.
