# What we refuse to optimize for
Groundtruth does not compete on flash, module count, or soft comfort. It
optimizes for honest money and the next action that gets a grower paid. If
a feature only makes the app look more sophisticated and does not serve
that job, it does not belong here — and a pull request that adds it will
be closed politely.
This list exists so the "why" stays sharp, and so builders do not "help"
by adding theater.
| We refuse | Because |
|-----------|---------|
| Feature-count contests | Modules are not the job. Cash-path truth is. |
| Pretty empty states that hide problems | Health is allowed to be ugly. A calm screen over a short shelf is a lie. |
| Soft money | Unpaid and unpriced must stay visible until they are settled or written off as themselves. |
| The phone as a second set of books | The phone proposes. Confirm happens on the PC. |
| AI as an authority over farm state | AI reads and advises. It never authors an event. |
| Dashboard wow as the sell | Speakers and mirrors are not the engine. |
| Hostage data or a mandatory cloud | Exit tax is zero. The core runs local-first and offline. |
| Busywork ranked above collect, cover, confirm, record | The morning loop ranks by path to cash. |
| "Automation completed the work" fiction | Reality is confirmed by a person, not assumed by a timer. |
| A shadow spreadsheet as the normal workflow | One record of the farm and the money. |
| Pipeline dollar values | Money exists only where it arrives. A lead is not revenue. |
## What this is not
Not a cloud service. Not a general farm ERP, a CRM, or an accounting
package. Not multi-user. Not phone-first. Not a dashboard built to flatter
you. Tools in this category often have broader boards and more modules;
this one is built around one job — non-negotiable money truth under tray
pressure — and it accepts being narrower everywhere else.
## The one-line version
We put the work into the engine and the chassis, not into upgrading the
speakers so the car sounds expensive while the drivetrain stays weak.
