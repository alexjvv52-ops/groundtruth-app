# 5. AI does not write farm truth
**Law.** AI does not write farm truth. Eyes only.
**Why.** A model can read a diagnosis packet, spot a pattern, draft a
sentence, and be wrong with total confidence. Any of those is fine as
advice. None of them may become a fact about the farm without a person
putting it there. The record has one author, and the author is not a
language model.
**What it forbids.**
- Any agent, assistant, or automation authoring an event in the farm log.
- "The AI reconciled it" as a state. If a number changed, a person recorded
  the change, on the PC, through the same door as every other change.
- Soft, AI-estimated numbers on screen as if they were counts or cash.
- A core loop that stops working without a model or a network. Everything
  a grower needs each morning runs offline on the desk.
**What it still allows.**
- External assistance: paste a diagnosis export into any tool you like and
  ask it what it sees. The export carries an **authority line** that says
  what it is — a PC-composed snapshot with its age — so a reader cannot
  mistake it for a live writer.
- Advice on the screen where it is honest to give it, marked as advice.
- AI in the building of the software. Much of this codebase was written
  with AI coding assistants — under signed decisions, one bounded change at
  a time, accepted only on the running application. The process pages
  explain how. The law above is about the farm record, not about who
  typed the code.
**How you can tell.** There is exactly one write door, and nothing behind
it has a model in it. If a feature ever needs an AI to mutate farm state
as its authority, it is refused, whatever it promises.
